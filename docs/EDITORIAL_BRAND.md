# 読書の羅針盤 — 編集とブランドの基本契約

## 存在理由
所蔵本の多さを競うのでなく、一冊読み終えた人が「なぜ次はこれなのか」を納得して進める。書誌→推薦の根拠→次の本→読書パスという関係を中心素材にする。普通の本リストに装飾を乗せるだけで終わらせない。

## 採用する企画
- 一冊から次への根拠がある具体的な比較、著者・作品の接続、意味のある読書順、異なる読み方が成立する作品。
- 読書パスは「順番」が画面で理解できる形にし、通常の書誌一覧と同じUIを強制しない。
- 文章は初見に必要な書名・著者・なぜ次かを先に。読後の感情を代弁するより、作品・形式・読みどころを具体的に説明。
- 作品詳細・推薦理由・パスのどこから入っても次へ進めるリンクを持たせる。

## 不採用にするもの
- 根拠のない「必読」「人生が変わる」、推薦理由のない大量羅列、根拠のない作家の影響関係。
- AIの架空体験談やレビュー、偽の著者コメント・人気順位。アフィリエイトによるランキングの操作。
- 全ページを同じカード・キャッチコピー・絵文字で埋める量産デザイン。意味のないインタラクション。

## 保守規則
- 書誌、推薦グラフ、既存slug、SEOのindex/noindex境界を維持する。欠けた本はリンクしない。
- ホームの「一冊のあとに、もう一冊。」は既存パス `existentialism-to-modern-thought` の最初の二冊の `step.noteJa` をそのまま表示。架空の推薦説明を別途ハードコードしない。パスが消えたら表示しない。
- 結果数やパス数は実データから生成し、静的カウントを放置しない。
- 長い書名・画面幅・キーボード・読みやすさを守る。書誌に確認できない事実を加えない。
